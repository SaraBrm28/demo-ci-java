# Projet Java Maven - CI/CD

![Java CI avec Maven](https://github.com/SaraBrm28/demo-ci-java/actions/workflows/ci.yml/badge.svg)

## Description

Projet Java utilisant Maven et JUnit 5 pour les tests unitaires.

## Fonctionnalités

- Addition
- Soustraction
- Multiplication
- Division
- Gestion de la division par zéro

## Technologies

- Java 17
- Maven
- JUnit 5
- GitHub Actions

## Exécuter les tests

```bash
mvn test
```
